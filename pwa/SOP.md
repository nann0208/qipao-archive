# 海派旗袍史料库 PWA 使用与维护指南

## 一、首次安装

### iPhone/iPad （Safari）
1. 在 Safari 浏览器中打开：https://nann0208.github.io/qipao-archive/pwa/
2. 点击底部工具栏 **分享按钮**（向上的箭头图标）
3. 向下滑动，选择 **"添加到主屏幕"**
4. 输入应用名称（可保持默认"海派旗袍史料库"），点击 **"添加"**
5. PWA 现在出现在你的桌面上，如同原生 App 一样

### 安卓手机 （Chrome/Edge）
1. 在浏览器中打开：https://nann0208.github.io/qipao-archive/pwa/
2. 点击右上角 **三点菜单**
3. 选择 **"安装应用"** 或 **"添加到主屏幕"**
4. 确认后，PWA 添加到桌面

### 其他浏览器
- **Firefox**：不支持 PWA 安装，但可以直接用浏览器访问
- **微信/QQ 内置浏览器**：可以正常打开，建议用"浮窗"或"复制链接到浏览器打开"

## 二、日常使用

### 页面导航
PWA 有 4 个主要页面，底部 Tab 切换：

| Tab | 功能 | 用途 |
|-----|------|------|
| 📊 首页 | 仪表盘 | 快速了解史料库统计信息（总数、类型分布、议题分布、来源排行） |
| 📋 史料 | 检索列表 | 搜索、筛选、浏览单条史料详细内容 |
| 📈 图表 | 可视化 | 查看年度分布、类型/议题占比、重要程度分布等图表 |

### 搜索和筛选
1. **全文搜索**：点击"史料"Tab，在搜索框输入关键词（支持题名、内容、关键词、作者等）
2. **按类型筛选**：点击"全部"旁的类型 chip（📰 报刊文章、🖼️ 图像等）
3. **按议题筛选**：点击"📌 议题 ▾"展开议题列表，选择一个议题
4. **清除筛选**：点击"全部" chip 恢复所有结果
5. **搜索清除**：搜索框右侧的"×"按钮清除输入

### 查看详情
1. 在列表中点击任意卡片
2. 进入详情页，显示完整信息：
   - 左侧：基本信息（编号、类型、来源、作者、时间、版本、重要程度、议题、舆论类型等）
   - 下方：核心内容、个人分析、原文摘录、关键词、批注、关联文档
3. 点击"← 返回列表"回到搜索结果

### 数据同步状态
- 顶部右侧显示同步状态：
  - **"同步中..."**：正在从 GitHub Pages 拉取最新数据
  - **"已同步 ✓"**：数据已更新到最新
  - **"使用缓存"**：离线或无网络，使用本地缓存数据
  - **"离线模式"**：完全离线，使用本地数据

## 三、数据更新流程

### 情况 A：在本地网页端（index.html）添加/修改了史料

**本地网页** 和 **PWA** 使用的数据源有区别：
- **本地网页**：从 `data/data.js` 加载，修改存储在浏览器 localStorage
- **PWA**：从 GitHub Pages 的 `data/data.js` 拉取

**更新 PWA 数据的步骤：**

1. 在电脑上打开本地网页 (file:///D:/AAA好好读书/aaa史料收集/shiliao_website/index.html)
2. 完成所有编辑、添加、删除操作
3. 点击右上角 **"⬇ 导出"** 按钮
4. 下载得到 `data.js` 文件，移动到 `D:\AAA好好读书\aaa史料收集\shiliao_website\data\` 文件夹
5. 打开 Git 终端或 VS Code，进入项目目录：
   ```bash
   cd D:\AAA好好读书\aaa史料收集\shiliao_website
   git add data/data.js
   git commit -m "更新史料数据：[简要说明，如「添加xx条新史料」]"
   git push origin main
   ```
6. 等待 3-5 秒，GitHub Pages 自动部署
7. 打开手机 PWA，顶部会显示"同步中..."，数据自动刷新
8. 刷新完后显示"已同步 ✓"，新数据即可用

### 情况 B：直接在 GitHub 网页上修改了代码或数据

如果你通过 GitHub 网页编辑器修改了 `data/data.js`，PWA 会在下次打开时自动同步（可能有几秒延迟）。

### 情况 C：清除 PWA 缓存

如果 PWA 显示旧数据不更新：
1. **iPhone**：设置 → Safari → 清除历史记录和网站数据
2. **安卓**：设置 → 应用 → [浏览器] → 存储 → 清除数据
3. 重新打开 PWA，强制重新下载数据

## 四、常见问题

### Q1：PWA 显示"无数据"或"加载失败"

**原因**：网络问题或第一次打开时数据加载超时

**解决方案**：
- 检查网络连接
- 等待 5 秒后刷新（拉下拉动页面）
- 关闭 PWA 重新打开
- 清除浏览器缓存后重试

### Q2：数据更新了但 PWA 还是显示旧数据

**原因**：浏览器缓存 Service Worker 旧版本

**解决方案**：
1. 等待 5 分钟让缓存过期
2. 或手动清除缓存（见上文"情况 C"）
3. 或在 PWA 里下拉刷新强制更新

### Q3：PWA 打不开图片或 PDF

**原因**：
- 原文档已被移动或删除
- 浏览器不支持该格式（尤其是 .docx Word 文档）

**解决方案**：
- PDF 和图片可以在手机预览
- Word 文档需要在电脑上打开，或在手机安装 Office 应用
- 检查本地网页里文档是否还存在

### Q4：搜索不到某条史料

**原因**：
- 关键词拼写错误
- 数据还未同步到 PWA

**解决方案**：
- 尝试更通用的关键词（如"旗袍"而不是"改良旗袍式样"）
- 检查顶部同步状态，确保显示"已同步 ✓"
- 在本地网页端搜索验证该史料是否存在

### Q5：PWA 很慢或经常卡顿

**原因**：
- 网络连接差
- 手机内存不足
- 缓存数据过多

**解决方案**：
- 切换网络或等待网络改善
- 关闭其他应用，释放内存
- 清除 PWA 缓存重新下载

## 五、定期维护建议

### 每周
- 打开 PWA 确认能正常访问和搜索
- 检查顶部同步状态是否显示"已同步 ✓"

### 每次编辑史料后
- 在本地网页导出 data.js
- 推送到 GitHub（见"情况 A"流程）
- 在手机 PWA 上搜索新添加的史料，确认同步成功

### 每月一次
- 检查 PWA 应用大小（手机设置里查看，如超过 100MB 可清除缓存）
- 浏览统计页面，关注议题和类型的趋势变化

### 遇到问题时
- 查看上文"常见问题"
- 如问题无法解决，记录错误信息（来自浏览器开发者工具）并反馈

## 六、技术细节

### PWA 文件结构
```
shiliao_website/
├── pwa/
│   ├── index.html       # PWA 主页面
│   ├── app.js           # 逻辑代码（搜索、筛选、图表等）
│   ├── style.css        # 样式
│   ├── sw.js            # Service Worker（离线支持）
│   ├── manifest.json    # PWA 配置（应用名称、图标等）
│   └── SOP.md           # 本文档
├── data/
│   └── data.js          # 史料数据（PWA 从这里拉取）
└── ...
```

### 数据流向
```
本地网页编辑
    ↓
导出 data.js
    ↓
推送到 GitHub
    ↓
GitHub Pages 部署
    ↓
PWA 定期检查并拉取最新数据
    ↓
手机端显示最新数据
```

### 离线工作原理
- Service Worker 缓存静态文件（HTML、CSS、JS）
- 首次下载的 data.js 存储在浏览器缓存
- 没有网络时，PWA 使用缓存数据
- 有网络时，自动检查并更新 data.js

## 七、安全提示

- ⚠️ **不要在公共 WiFi 打开 PWA**（如果数据包含敏感内容）
- ⚠️ **定期清除浏览器缓存**（尤其是共享设备）
- ⚠️ **备份本地网页的 data.js**（定期导出并保存）
- ✓ **PWA 数据存储在设备本地**，不会上传到云端
